## 제약 조건

- 원문 발언, 이 글의 해석, 가상 예시를 구분한다. 특정 컴파일러 프로젝트나 전체 AI 성능의 검증 결과처럼 서술하지 않는다.
- 그래프의 눈금, 함수식, 시간당 생산성 수치를 만들어내지 않는다.
- Adaptive SDD는 설명·비교 자료이며 이 저장소에 새 정책으로 도입하지 않는다.
- 테마, 빌드 설정, 검색 구현, 배포 워크플로는 유지한다.
- 글 작성과 목록 연결까지 진행한다. 원격 게시 여부는 실제 수행 사실대로 보고한다.

- Jekyll 빌드와 `git diff --check`를 실행한다. 미실행·실패 검사는 성공으로 기록하지 않는다.
- 목록 변경은 작성 이후 별도의 리뷰 단계에서 링크·순서·본문 무관 변경 여부를 점검한다.

## 원고 작성 단계의 검증 결과

- 영상 22:16의 빨간 궤적, 25:56의 초록 궤적, 46:40의 Effort/Output/Outcome/Mission 그림을 직접 확인했다. Features가 가로축, Futures가 세로축이며 원본에 시간 눈금이나 실측 수치는 없다.
- 본문 도식 7개, 표 6개, 표지 1개를 추가했다. SVG 원본 8개의 XML 파싱이 성공했다. 도식 생성기는 `_meta/scripts/draw-kent-beck-diagrams.py`에 보존했다.
- 제목·H1 일치, 날짜·카테고리, 본문의 로컬 링크/이미지 경로 11곳, 단독 글 10편의 순번 1~10을 확인했다.
- 목록 변경을 별도로 리뷰해 홈·단독 글 목록의 새 링크가 한 번씩 있으며 가장 위에 놓였음을 확인했다. 기존 글 9편은 `nav_order` 외의 내용이 변경되지 않았음을 HEAD와 비교했다.
- 기존 공개 사이트 CSS와 Python Markdown을 사용하는 로컬 미리보기에서 데스크톱과 모바일 화면을 확인했다. 이미지 8개 로드 성공, 표 6개 렌더링, 모바일 페이지 가로 넘침 없음. 도식 첫 검토에서 발견한 주석 겹침은 수정 후 다시 확인했다.
- `git diff --check` 통과. 새 원고의 줄 끝 공백도 별도 확인했다.
- **Jekyll 빌드 미실행:** `bundle exec jekyll build --baseurl /ai-agent-diary`를 시도했으나 Ruby/Bundler가 설치되지 않아 실행되지 않았다. 로컬 미리보기는 Jekyll/Kramdown 빌드 성공의 증거가 아니다.
- 로컬 원고와 목록 연결을 완료했다. 원격 push, PR 생성, 공개 배포는 하지 않았다.
