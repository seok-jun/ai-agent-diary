- 홈(`index.md`)은 `.archive-*` 커스텀 카드 디자인.
- 시리즈·단독 README 3개는 밋밋한 markdown 불릿 목록 → 홈에서 진입하는 순간 디자인이 단절됨.
- 링크 텍스트에 `1편.` 등이 제목과 중복되어 지저분함.
- 홈이 곧 개편 예정이라, 시리즈 페이지가 홈의 `.archive-*`에 묶이면 안 됨.
