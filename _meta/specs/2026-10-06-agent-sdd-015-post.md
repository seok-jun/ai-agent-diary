# Agent SDD 연재 15편 (실험장 재구축) 게시 명세

## AS-IS

- Agent SDD 연재는 14편까지 게시되어 있고, 홈·연재 목록·저장소 소개의 편수도 14편이다.
- 14편은 격리 때문에 실험이 두 번 멈춘 기록이고, 격리를 더 단단하게 만들지 여부는 "아직 못 정했다"로 끝난다.
- 15편 초안은 `_meta/drafts/015-rebuilding-experiment-environment.md`에 있다. front matter·게시일 줄·내부 링크·섬네일이 없고, 도식 네 개가 mermaid 코드 블록이다. 이 사이트는 mermaid를 켜지 않아 코드로 보인다.
- 초안을 비공개 개발 저장소의 기록과 대조하니 수치는 일치하지만 빠진 내용이 있다. 실제 모델 호출 11회 중 4회만 나오고, 리허설과 실제 호출의 순서가 바뀌어 읽히며, 진단 과제의 실패를 기록보다 강하게 해석한다.

## TO-BE

- 2026-10-06자로 연재 15편을 게시한다. 초안의 구성과 문장은 유지하고, 기록과 어긋나거나 빠진 부분만 고친다.
  - 실제 호출 11회의 내역과, 앞의 7회에서 비교할 수 있는 쌍이 나오지 않은 사실을 싣는다.
  - 리허설이 실제 호출 4회 뒤였다는 순서를 바로잡는다.
  - 13편과 같은 것(A/B의 차이)과 달라진 것(모델·추론 수준, 과제, 판정용 검사 공개 여부, 횟수와 순서)을 나눠 적는다.
  - 수정 전 코드의 기준선, 모델 작업 마감, 후보 명령 실패 수를 싣고, 진단 과제의 해석 범위를 기록에 맞춘다.
  - 14편 끝의 예고(방법론 연결 구현)와 주제가 다른 점을 도입부에서 한 줄로 잇는다.
- mermaid 도식 네 개를 SVG로 바꾸고, 섬네일 1장을 넣어 front matter `image`에 연결한다.
- 연재 목록, 홈의 시리즈 카드, 저장소 소개에 15편과 편수(15편)를 반영한다.

## 제약 조건

- 공개 글이 비공개 저장소 링크에 의존하지 않도록 판정표와 결과 수치를 본문에 직접 싣는다. 과제의 제품 내용은 초안 수준의 추상도를 유지한다.
- 수치는 개발 저장소의 기록 그대로 쓴다. 판정까지 가지 못한 호출과 보류된 해석을 성공처럼 쓰지 않는다.
- 이미 게시한 14편 본문은 고치지 않는다.
- 도식과 섬네일은 12~14편과 같은 팔레트·글꼴 스택·구성을 따른다.
- 테마, `_config.yml`, 검색 설정, Pages 워크플로는 변경하지 않는다. mermaid를 켜지 않는다.

## 검증 기준

- Jekyll 빌드와 `git diff --check`가 성공한다.
- 홈·연재 목록·사이드바에서 15편이 열리고, 본문의 내부 링크가 연결된다.
- 표와 SVG 도식, 섬네일이 렌더링된다.
- 빌드 결과의 `og:image`가 15편 섬네일을 가리킨다.

## 검증 결과 (작성 시점)

- `git diff --check` 통과. 새 파일에 줄 끝 공백 없음.
- front matter 일곱 항목과 `title`·H1 일치, 본문 내부 링크 10개의 permalink·이미지 파일 존재, 표 9개의 열 수 일치, mermaid 블록 0개를 스크립트로 확인했다.
- SVG 네 개와 섬네일은 헤드리스 Chrome으로 렌더링해 글자 겹침과 잘림을 확인했다.
- 본문 수치는 개발 저장소의 일지와 기계 판독 요약(교정 쌍, 진단 쌍, 오프라인 리허설, 앞선 실패 호출)에 대조했다.
- 작성 환경에 Ruby가 없어 Jekyll 빌드는 실행하지 못했다. 병합 후 Pages 빌드와 공개 URL에서 표·도식 렌더링, 홈 "최근 글" 순서(15편이 NEW), `og:image`를 확인해야 한다.
