# 토큰 사용량과 개발 활동 비교

## 분류

- Priority: P2. 토큰 그래프만으로 병합 PR·완료 이슈의 기간별 변화를 비교하기 어렵다.
- SDD grade: Medium. 기간 교집합과 파생 지표 계산, 차트·안내 표시를 함께 바꾼다.

## AS-IS

- 일별·월별·누적 기록과 토큰 막대그래프를 표시한다.
- Codex와 GitHub의 수집 시작일·종료일이 다를 수 있다.
- 변경량 카드·표 열 제거는 현재 로컬 수정에 포함돼 있다.

## TO-BE

- 같은 시간축의 토큰·병합 PR·완료 이슈 차트를 표시한다. 단위가 다른 지표는 별도 차트와 축 최댓값을 사용한다.
- 선택한 기간과 두 소스의 수집 구간이 겹치는 날짜만 비교한다. 누적 보기에서는 월별로, 월별 보기에서는 일별로 표시한다.
- 사용자 선택에 따라 공통 기간의 총건수 / 총토큰 × 1,000,000으로 PR·이슈 비율을 각각 표시한다.
- 토큰이 0이거나 공통 수집 기간이 없으면 비율을 계산하지 않는다. 토큰이 양수이고 건수가 0이면 0이다.
- 비율은 작업 품질·규모나 AI 기여도를 평가하지 않으며 토큰 소비와 완료 시점에는 차이가 있음을 안내한다.

## 영향 파일

- `docs/assets/activity/dashboard.js`, `docs/activity.md`, `docs/_sass/custom/custom.scss`
- `_meta/activity/dashboard.test.cjs`

## 제약

- 수집기·공개 JSON 스키마·PAT·예약 작업·Pages 워크플로·내비게이션·검색·`_config.yml`은 변경하지 않는다.
- 기존 통계 JSON과 사용자 로컬 파일을 보존한다. 외부 차트 의존성을 추가하지 않는다.

## 검증 기준

- 기간 교집합, 부분 월, 0토큰, 미수집, 가중 비율 계산에 대한 JavaScript 테스트를 통과한다.
- 데스크톱·모바일에서 차트·기간 선택·표·미수집 안내를 확인한다.
- Jekyll 빌드와 `git diff --check`를 확인하고 실행 불가 항목은 구분해 기록한다.

## 검증 결과

- JavaScript 테스트 8개 통과: 기존 집계 동작, 공통 기간, 부분 월, 가중 비율, 0토큰·0건·미수집을 확인했다.
- Sass 컴파일 통과. 기존 배포 테마에 로컬 Markdown·JavaScript·CSS·통계 JSON을 적용한 임시 브라우저 미리보기에서 데스크톱 1280px·모바일 390px을 확인했다.
- 두 너비에서 세 차트, 네 개 기존 지표, 두 개 비율, 다섯 개 표 열, 일별·월별·누적 전환, 미수집 안내, 페이지 가로 넘침 없음, 브라우저 예외 없음을 확인했다.
- `git diff --check` 통과. 통계 JSON과 수집기·설정·워크플로는 이 작업에서 수정하지 않았다.
- 전체 Jekyll 빌드는 로컬 Ruby/Bundler가 없고 WSL도 설치되지 않아 미실행이다. 위 미리보기는 전체 Jekyll 빌드를 대체한 것으로 보고하지 않는다.

## 백로그

- Ruby 3.2 빌드 환경에서 전체 Jekyll 빌드 검증 후 배포한다. 현재 변경은 로컬 상태다.
