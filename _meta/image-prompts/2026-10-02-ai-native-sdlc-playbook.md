# AI-Native SDLC 플레이북 글 섬네일 제작 기록

- 제작 방식: HTML·SVG로 직접 구성한 뒤 Chromium(Playwright)으로 1600×900 PNG 캡처. 이미지 생성 모델은 쓰지 않았다.
- 글꼴: Pretendard (npm `pretendard` 패키지의 OTF)
- 게시 자산: `docs/assets/images/standalone/2026-10-02-ai-native-sdlc-playbook/thumbnail.png`
- 용도: 글 상단 및 Open Graph / Twitter 공유 이미지

## 구성

- 배경: 아주 옅은 청회색(`#f4f7fb`), 모서리에 옅은 원 두 개
- 왼쪽: 상단 문구 "ANTHROPIC PLAYBOOK · AI-NATIVE SDLC", 제목 "코드는 더 이상 / 병목이 아니다"(병목만 파란색 `#2f6fde`), 부제 "여섯 단계가 하나의 고리가 될 때", 산출물 칩 "intent.md → spec.md → plan.md → PR"
- 오른쪽: 기획·설계·구현·테스트·배포·운영 여섯 원이 화살표로 이어진 고리, 가운데 "사람의 판단 / 승인 게이트"
- 단계 색은 본문 도식(`sdlc-loop.svg` 등)과 같은 팔레트를 쓴다.
